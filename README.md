# AI Пульт

Один экран, одна кнопка, два агента. Kimi анализирует исходники germes-pult, DeepSeek проверяет предложения. Только чтение.

GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root). Адрес: https://gatamylat.github.io/ai-pult/

На iPhone: открыть в Safari, ввести GitHub token (Contents: Read-only для germes-pult), Kimi API key и DeepSeek API key, нажать «Анализировать». Поделиться → На экран «Домой».

Ключи хранятся только в localStorage устройства, не публикуются в GitHub. Это не защищённое хранилище; ограничьте права и расходы. Для прямых запросов API требуется поддержка CORS провайдерами: если CORS запрещён, браузер сообщит об ошибке.

Новые модули — только по команде владельца.
