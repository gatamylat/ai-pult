# AI Пульт

Личный веб-пульт для компьютера и iPhone. Два режима используют одну библиотеку текстовых документов, Skills и подтверждённых фактов.

- **Собрать промпт.** Подберите материалы, проверьте, что вошло, и скопируйте результат в нужный чат. Работает с локальной библиотекой без ключей моделей.
- **Выполнить задачу.** Выберите Claude, DeepSeek или «Вместе». Ключи независимы и хранятся на этом устройстве. В совместном режиме Claude отвечает, DeepSeek проверяет, Claude уточняет ответ. При сбое проверки сохраняется уже полученный ответ.
- **Личная библиотека.** В настройках создайте личный код и подключите его на первом устройстве, затем введите тот же код на втором. Библиотека хранится локально и синхронизирует зашифрованные записи через существующую конфигурацию Firebase. Для ранее созданной локальной библиотеки воспользуйтесь экспортом и импортом копии. Копия содержит тексты библиотеки и историю в открытом виде.
- **На iPhone.** Откройте опубликованное приложение в Safari и добавьте его на экран «Домой».

GitHub Pages публикует корень репозитория. Для локального запуска подойдет любой статический HTTP-сервер на localhost.
